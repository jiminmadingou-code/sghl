📋 Guide d'installation étape par étape

1
Télécharger le fichier APK

Appuyez sur le bouton "Télécharger l'APK" ci-dessus. Le fichier se télécharge dans votre dossier Téléchargements.

2
Autoriser les sources inconnues

Allez dans Paramètres → Sécurité (ou Applications → Autoriser sources inconnues selon votre Android). Activez l'option pour votre navigateur.

3
Ouvrir le fichier téléchargé

Ouvrez le gestionnaire de fichiers, allez dans Téléchargements et appuyez sur SGHL-Patient.apk.

4
Confirmer l'installation

Android affiche un écran de confirmation. Appuyez sur Installer puis Ouvrir une fois terminé.

5
Se connecter

Utilisez vos identifiants fournis par le CHU SGHL. Contactez l'accueil si vous n'avez pas encore de compte.
